## 💻 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de consolidar conceitos fundamentais do desenvolvimento web front-end, focando na criação de uma ferramenta funcional e prática para o dia a dia. 

A aplicação permite que o usuário organize sua rotina de forma rápida, adicionando novas pendências, marcando atividades já concluídas e removendo itens de forma dinâmica e fluida.

---

## 🛠️ Tecnologias Utilizadas

A estrutura da aplicação conta com as seguintes tecnologias:

* **HTML5** – Estruturação semântica do layout e dos campos de entrada.
* **CSS3** – Estilização moderna, design responsivo (adaptável para celulares e computadores) e transições suaves.
* **Design Escuro (Dark Theme)** – Interface elegante em tons escuros para garantir conforto visual e reduzir a fadiga ocular durante o uso prolongado.
* **JavaScript (ES6+)** – Lógica de programação para gerenciar dinamicamente as tarefas (criar, marcar como concluída e excluir) através da manipulação de eventos e elementos do DOM.

---

## ✨ Funcionalidades

- [x] **Adicionar Tarefas:** Permite criar novas tarefas de forma rápida pressionando o botão ou a tecla "Enter".
- [x] **Marcar como Concluída:** Feedback visual (como texto riscado ou alteração de cor) ao concluir uma atividade.
- [x] **Exclusão Individual:** Botão dedicado para remover tarefas específicas da lista.
- [x] **Interface Otimizada:** Visual minimalista em Dark Mode e totalmente responsivo.
- *(Opcional - se seu projeto salvar os dados, mantenha a linha abaixo)*
- [x] **Persistência de Dados:** Uso de `LocalStorage` para manter as tarefas salvas mesmo após fechar ou atualizar o navegador.
